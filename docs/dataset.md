# 학습 데이터 구성

## 클래스와 장수

직접 모은 **총 240장**으로 3클래스 객체 탐지 모델을 학습시켰습니다. (결선 발표자료 기준)

| 클래스 | 장수 | 의미 |
|---|---:|---|
| `helmet` | 100장 | 헬멧을 제대로 착용한 상태 |
| `not_helmet` | 70장 | 모자 등 헬멧이 아닌 것을 쓰고 있는 상태 |
| `person` | 70장 | 머리에 아무것도 쓰지 않은 사람 |
| **합계** | **240장** | |

## 클래스를 3개로 나눈 이유

처음에는 "헬멧이 있다 / 없다" 2클래스로 생각했습니다. 그런데 모자를 쓰면 헬멧으로 오인될 가능성이 있어서, **헬멧과 비슷하게 생겼지만 헬멧이 아닌 것**을 따로 `not_helmet`으로 학습시켰습니다.

`person` 클래스는 두 가지 역할을 합니다.

1. 머리에 아무것도 안 쓴 사람을 "미착용"으로 판별
2. **화면에 잡힌 사람 수를 세서 다인(2인 이상) 탑승을 판별** — 결선에서 추가한 기능

그래서 시연 화면을 보면 한 사람이 헬멧을 쓰면 `helmet`, 다른 한 사람이 안 썼으면 `person`으로 각각 박스가 잡히고, 이 박스 개수로 2인 탑승을 판단합니다.

## 한계 (솔직하게)

- **240장은 턱없이 적습니다.** 실제 도로 환경(야간, 우천, 역광, 다양한 헬멧 종류, 먼 거리)을 전혀 담지 못했습니다.
- 촬영 장소와 조명이 비슷한 사진이 많아 **데이터 다양성이 부족**합니다. 시연 영상에서도 각도가 바뀌면 신뢰도가 크게 떨어지는 게 보입니다.
- **학습/검증/테스트 분리와 성능 측정을 하지 않았습니다.** mAP·precision·recall·FPS 수치를 하나도 기록하지 않아서, 지금 이 모델이 얼마나 잘 맞추는지 숫자로 말할 수 없습니다.
- 데이터 수집 방법(직접 촬영 / 웹 수집 비율)과 라벨링 도구도 기록으로 남기지 않았습니다.
- 학습 데이터에 제3자 얼굴 사진이 포함되어 있어 **이 레포에는 샘플 이미지를 올리지 않았습니다.** 지금이라면 수집 단계에서 초상권·개인정보 문제를 먼저 정리하고 시작했을 것입니다.

> 시연 화면에 보이는 `helmet 0.84`, `person 0.59` 같은 숫자는 그 프레임의 탐지 신뢰도(confidence)일 뿐, 모델의 정확도 지표가 아닙니다.
